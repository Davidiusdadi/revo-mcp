# corpus/overlay

Our own VOKO articles, in the same dialect and DTD as `vendor/revo-fonto/revo/`.
The corpus builder merges this directory over the submodule **by file name**:
a file here with the same name as an upstream article replaces it; a new name
adds an article.

License: the articles here are ReVo content and, like `vendor/revo-fonto`,
licensed under the GNU GPL v2 only (see the repository's `LICENSE`).

Rules:

- Anything that ReVo itself would accept belongs upstream: edit the article in
  `vendor/revo-fonto` on a fork branch and open a PR instead of overlaying it.
- Put a file here only for content ReVo would not take (or not yet). Start it
  with a comment saying why, and what upstream article it replaces, if any.
- Derived data (segmentations, links, vectors) is never authored here; it lives
  in the enrichment tables of `data/voko.db` and is regenerated by passes.

Note: affixes need no overlay — ReVo already has full articles for them (e.g.
`ar.xml` with 13 derivations); a stub here would replace them.
